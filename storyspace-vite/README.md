# Storyspace Alpha

UX prototype proving a semantic navigation model for literary projects:

**Canvas ↔ Flow ↔ Note**

## Stack

- React 19.3
- TypeScript 7
- Vite 8
- React Flow 12

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is static and has no runtime CDN dependency.
